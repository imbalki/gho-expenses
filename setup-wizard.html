Get your tracker live

Five short stops. At each one you sign into your own account on that service — nothing here ever asks for a password, and nothing you type is sent to us. Steps 1–3 get the app running; step 4 (voice notes + Telegram) is optional and can be done anytime later.

1

Create your database

This is where every expense, project, and photo gets stored. Free to start, no card needed.

Create free database ↗
  1. Sign in with Google or email, name the project anything, set a database password — write it down, you'll use it in a moment.
  2. Pick the region closest to you and click Create. Takes about 2 minutes.
  3. Once it's ready: left sidebar → Storage → New bucket → name it exactly receipts → turn on Public bucket → Create.
  4. Left sidebar → gear icon (Project Settings) → API Keys. Copy the Project URL at the top. Then copy the key called anon / public (newer projects may call it publishable, starting with sb_publishable_... — same thing, use that). Then click Reveal on the key called service_role (newer projects: secret, starting with sb_secret_...) and copy it too. Keep this tab open, you need all three in step 3.
  5. Near the top of the page, click the green Connect button → make sure the connection-string tab is selected → choose Session pooler (not "Transaction pooler", not "Direct connection" — session pooler is the one that won't break when the app builds). Copy the URI shown and replace [YOUR-PASSWORD] in it with the password from step 1.

Supabase has been renaming a few things lately — if a label above doesn't match exactly what you see, look for the closest match; the values matter, not the exact wording.

2

Get your OpenRouter key & pick your AI models

One key runs everything AI-related in this app: reading receipt photos, sorting expenses into categories, understanding typed text, and transcribing voice notes.

Get key ↗

It needs a small top-up to actually work — after making the key, go to Settings → Credits and add about $5. That's the only step in this whole setup that costs real money, and it should last months at normal use.

3

Deploy the app

This puts the tracker on the internet, on Vercel's free plan.

Deploy to Vercel ↗
  1. Sign in to Vercel (Google, GitHub, or email — this is just to prove it's you; you won't see or need to touch any code).
  2. It'll show a row of boxes to fill in. Paste in the values you collected in steps 1–2. Here's what each one is:
DATABASE_URL → the connection string, step 1.5
NEXT_PUBLIC_SUPABASE_URL and SUPABASE_URL → same value, Project URL, step 1.4
NEXT_PUBLIC_SUPABASE_ANON_KEY → anon / publishable key, step 1.4
SUPABASE_SERVICE_ROLE_KEY → service_role / secret key, step 1.4
SUPABASE_RECEIPTS_BUCKET → leave as receipts
OPENROUTER_API_KEY → from OpenRouter, step 2
OPENROUTER_TEXT_MODEL / OPENROUTER_VISION_MODEL / OPENROUTER_TRANSCRIBE_MODEL → leave as filled in — these match what you picked in step 2
MONTHLY_AI_BUDGET_USD → leave as 5 (raise it later if you need to)

Click Deploy. It takes 1–2 minutes and sets up the database tables by itself — nothing else to run anywhere. You'll get a link like https://your-app.vercel.app — save it, you need it below.

The web capture page works right away with photos, typed text, and voice notes — no extra signup needed. The Telegram bot is a separate, optional way in — step 4 below covers it, whenever you're ready. Nothing breaks without it.

4

Add the Telegram bot

Optional · do anytime

Skip this for now if you like — the app already works with photos, typed text, and voice notes on the capture page. Come back whenever you want your team messaging a bot instead.

Telegram bot

Open BotFather, send /newbot, give it a name and a username ending in bot. Copy the token it replies with.

Open BotFather ↗
A made-up password that stops strangers from pretending to be Telegram.

Now add these to your already-deployed app: on Vercel, open your project → Settings → Environment Variables → add TELEGRAM_BOT_TOKEN and TELEGRAM_WEBHOOK_SECRET (your secret phrase above) → Save. Then go to the Deployments tab, open the newest one, and click Redeploy so it picks up the new values.

Then connect the bot — one click, runs in your own browser, nothing sent anywhere except to Telegram:

A new tab opens showing something like {"ok":true,...} — that means it worked. If it shows an error instead, double-check the three boxes above and that you redeployed after adding the environment variables.
